# Vaja_RPO

## Spletna trgovina s športno opremo

Izdelava kompletne spletne trgovine s športno opremo za pedagoške namene, pri predmetu RPO na RST MAG FIŠ UNM.

## Funkcionalnosti

Funkcionalnosti se delijo na **obvezne** (ocena 6) in **neobvezne** (ocena >6)

### Obvezne
- [x] Začeti README
- [ ] Uporabniki: prijava, registracija in profil, pozabljeno geslo
- [ ] Produkti: seznam produktov, meni, opisi, informacije o produktih
- [ ] Naročila: pregled preteklih naročil, oddajanje naročila, prekinitev naročila
- [ ] košarica
- [ ] izbira jezika
- [ ] dokumentacija
- [ ] podatkovna baza
### Neobvezne
- seznam poslovalnic
- ocene in mnenja o produktu
- slike produktov
